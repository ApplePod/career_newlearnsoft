개발자 (풀잇 웹서비스 풀스택)

수능 준비생을 위한 AI 모의고사 웹서비스 풀잇을 함께 만들 개발자를 찾습니다. 기획 단계부터 함께 하며, 서비스의 뼈대를 직접 짜게 됩니다.

정규직 신입 가능 서울 관악구 채용 인원 1명
회사/팀 소개

풀잇은 웹(+태블릿) 기반 AI 모의고사 서비스로, 학생이 매일 문제를 풀고 채점·오답노트·약점 분석까지 이어지는 학습 루프를 제공합니다. 현재 로그인/본인인증, 문제 풀이 화면, 결제(구독) 등 핵심 기능을 개발 중이며, 7월 말 정식 오픈을 목표로 막바지 개발을 진행하고 있습니다.

주요 업무
  • 풀잇 웹서비스 프론트엔드·백엔드 개발 (신규 기능 위주)
  • 회원가입/로그인(소셜 로그인 포함), 결제·구독 연동
  • 문제 풀이·채점·오답노트 화면 및 API 개발
  • DB 스키마 설계 및 성능 최적화
  • 서비스 운영 중 발생하는 버그 대응 및 안정화
자격 요건
  • 웹 서비스 풀스택(또는 백엔드 중심) 개발 역량 (신입 가능, 경력 2년 이상 우대)
  • RESTful API 설계 및 DB 설계 경험
  • 회원 인증(OAuth 등), 결제 연동 경험
  • Git 기반 협업 및 코드 리뷰 경험
우대 사항
  • 교육·시험/문제풀이 서비스 개발 경험
  • 대용량 트래픽 대응 또는 실시간 채점 로직 개발 경험
  • 초기 스타트업에서 서비스를 처음부터 만들어본 경험
이런 분이면 잘 맞아요
  • 기획이 덜 정해진 상태에서도 방향을 잡아가며 개발할 수 있는 분
  • 빠르게 만들고 빠르게 고치는 사이클에 익숙한 분
