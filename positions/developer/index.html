개발자 (풀잇 웹서비스 풀스택)

수능 준비생을 위한 AI 모의고사 웹서비스 풀잇을, 상세히 준비된 기획·정책 문서를 바탕으로 처음부터 실제로 만들어갈 개발자를 찾습니다. 서비스의 뼈대를 직접 짜게 됩니다.

정규직 신입 가능 서울 관악구 채용 인원 1명
회사/팀 소개

풀잇은 웹(+태블릿) 기반 AI 모의고사 서비스로, 학생이 매일 문제를 풀고 채점·오답노트·약점 분석까지 이어지는 학습 루프를 제공합니다. 서비스 기획과 문항 데이터셋, DB 스키마·정책 문서(문제 렌더링, 알림톡 발송 등)는 상세히 준비되어 있지만, 실제 사용자가 쓸 수 있는 애플리케이션은 아직 없는 단계입니다. 현재 백엔드에는 초기 인증(Google OAuth) 골격만 있으며, 이를 기반으로 서비스 전체를 처음부터 함께 구현할 개발자를 찾습니다.

주요 업무
  • 백엔드 코어 구축 — 인증·사용자·문제 도메인·문제풀이·리포트 API 개발
  • 사용자용 웹(+태블릿) 프론트엔드 개발 — 문제 풀이·채점·오답노트 화면
  • 운영 어드민 도구 개발 — 문제 관리·운영 모니터링
  • 이미 정의된 DB 스키마·정책 문서를 실제 시스템으로 구현
  • MVP 범위의 핵심 문제풀이 흐름 우선 개발
자격 요건
  • 웹 서비스 풀스택(또는 백엔드 중심) 개발 역량 (신입 가능, 경력 2년 이상 우대)
  • RESTful API 설계 및 DB 설계 경험
  • OAuth 등 회원 인증 연동 경험
  • Git 기반 협업 및 코드 리뷰 경험
우대 사항
  • 교육·시험/문제풀이 서비스 개발 경험
  • 기획·정책 문서를 바탕으로 서비스를 처음부터 구축해본 경험
  • 대용량 트래픽 대응 또는 실시간 채점 로직 설계 경험
이런 분이면 잘 맞아요
  • 상세한 기획·정책 문서를 실제 동작하는 시스템으로 옮기는 과정을 즐기는 분
  • 빠르게 만들고 빠르게 검증하는 MVP 개발 사이클에 익숙한 분
