Passnote Android

AOS 개발자 (패스노트)

iOS 패리티로 1차 완성된 패스노트 Android 앱을, 더 빠르고 안정적으로 다듬어갈 개발자를 찾습니다.

정규직 신입 가능 서울 관악구 채용 인원 1명
회사/팀 소개

패스노트는 PDF 위에 필기하고, 스크랩하고, 공부하는 올인원 학습 노트 앱입니다. 펜·지우개·도형·라쏘 등 다양한 필기 도구와 S펜을 지원합니다. Android 앱은 PDF 뷰어·필기·스크랩·계정/로그인·구매 등 iOS 패리티 기준 1차 완성을 이미 마쳤고, 현재 Jetpack Compose 기반 필기 렌더링 성능 고도화, 크래시·메모리 안정화, 서버(S3) 기반 백업·복원 등 후속 개발이 활발히 진행되고 있습니다.

주요 업무
  • 패스노트 Android 앱 신규 기능 개발 및 기존 기능 고도화 (iOS와 정합 유지)
  • Jetpack Compose Canvas 기반 필기(펜·지우개·라쏘) 엔진 성능 최적화
  • 대용량 필기 노트의 로드·저장 성능, 라쏘 대량 선택 등 성능 튜닝
  • 서버(S3) 기반 크로스플랫폼 백업·복원 기능 개발
  • iOS 팀과 데이터 스키마·기능 정합 협업
자격 요건
  • Android 앱 개발 역량 — Kotlin, Jetpack Compose (신입 가능, 경력 2년 이상 우대)
  • Canvas 기반 드로잉/커스텀 렌더링 또는 터치·펜 입력 인터랙션 구현 경험
  • REST API 연동 및 비동기 처리 경험
  • Git 기반 협업 경험
우대 사항
  • 필기·드로잉 엔진 또는 커스텀 렌더링 파이프라인 최적화 경험 (라쏘 선택, 잉크 렌더링 등)
  • S Pen 등 스타일러스 입력 처리 경험
  • 대용량 데이터 처리 성능 튜닝 경험
이런 분이면 잘 맞아요
  • 이미 1차 완성된 앱의 완성도를 한 단계 더 끌어올리는 과정을 즐기는 분
  • iOS 서비스 사양을 참고하며 꼼꼼하게 정합을 맞출 수 있는 분
