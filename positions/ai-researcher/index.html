AI 연구원 (문항 생성·개인화 추천)

수능형 AI 모의고사 서비스 풀잇에서, 수학·영어 문항을 생성·정제하고 학생 개개인의 약점을 진단해 다음 문제를 추천하는 AI 연구원을 모십니다.

정규직 신입 가능 서울 관악구 채용 인원 1명
회사/팀 소개

뉴런소프트는 검수 가능한 AI로 K-수능 문항을 생성하는 Pass AI 엔진을 기반으로, 자체 서비스 풀잇(PullIt)을 운영합니다. 풀잇은 학생이 매일 푸는 문제 데이터를 쌓아 약점 단원·유형을 진단하고, 그에 맞는 다음 문제를 추천하는 적응형 학습 서비스입니다. 수학·영어 문항을 생성·가공·정제하는 파이프라인을 계속 고도화하는 동시에, 이 데이터를 학생 개개인에게 어떻게 연결할지가 다음 과제입니다.

주요 업무
  • 수학·영어 문항 생성 모델 개발 및 Pass AI 생성 파이프라인 고도화
  • 생성된 문항 데이터 가공·정제 및 품질 분석
  • 학생 풀이 로그 기반 약점 단원·유형 진단 로직 설계·개선
  • 데일리 추천 큐(오늘의 문제) 추천 알고리즘 개발 및 A/B 테스트
  • 지식그래프·문항 난이도 데이터를 활용한 개인화 추천 모델 구축
  • 풀이 데이터 파이프라인(수집→분석→추천) 설계 및 운영
자격 요건
  • Python 기반 데이터 분석·ML 역량 (신입 가능, 실무 경험 2년 이상 우대)
  • LLM/생성형 AI 기반 텍스트·문항 생성 파이프라인 개발 경험
  • 추천 시스템, 개인화, 또는 교육 데이터 분석 경험
  • SQL 기반 대용량 로그 데이터 처리 경험
  • 가설 검증형 실험(A/B 테스트) 설계·해석 경험
우대 사항
  • 교육 도메인(수능·내신·문제풀이 서비스) 데이터 경험
  • 지식그래프, 문항반응이론(IRT) 등 학습분석 이론 이해
  • 생성 문항 품질 평가 지표 설계 경험
  • 스타트업에서 데이터 인프라를 처음부터 구축해본 경험
이런 분이면 잘 맞아요
  • 추천 결과를 "감"이 아니라 지표와 실험으로 검증하는 분
  • 학생 한 명 한 명의 학습 패턴에 관심이 있는 분
  • 작은 팀에서 기획부터 배포까지 빠르게 돌리는 데 익숙한 분
기술 스택

Python · SQL · Pandas · scikit-learn · LLM · 지식그래프 · A/B 테스트
