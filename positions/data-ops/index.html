데이터 가공·정제·분석 (계약직)

Pass AI가 생성한 수학·영어 문항 데이터를 검수하고 가공·정제하는 업무를 함께할 분을 찾습니다. 문항 품질을 사람의 눈으로 직접 확인하고 다듬는, Pass AI 품질을 실제로 완성하는 역할입니다.

계약직 신입 가능 서울 관악구 채용 인원 1명
회사/팀 소개

뉴런소프트는 검수 가능한 AI로 K-수능 문항을 생성하는 Pass AI 엔진을 기반으로, 자체 서비스 풀잇(PullIt)을 운영합니다. Pass AI가 생성한 문항은 Solver 교차검증·교과과정 매핑 등 자동 검수를 거치지만, 최종 품질은 사람이 한 번 더 확인하고 다듬는 과정이 필요합니다. 이 역할은 문항 데이터를 가공·정제하며 Pass AI의 품질을 실제로 완성하는 자리입니다.

주요 업무
  • Pass AI가 생성한 수학·영어 문항 데이터 검수 및 오류 태깅
  • 문항 데이터 가공·정제(포맷 정리, 중복 제거, 메타데이터 라벨링)
  • 데이터 품질 이슈 리포트 작성 및 AI 연구팀과 개선사항 공유
  • 정제 기준·가이드라인 수립 지원
자격 요건
  • 엑셀/스프레드시트 등 데이터 처리 도구 활용 가능 (신입 가능)
  • 꼼꼼하고 반복 작업에도 집중력을 유지하는 성향
  • 기본적인 수학 또는 영어 교과 내용 이해
우대 사항
  • SQL 또는 Python 기초 활용 가능자
  • 데이터 라벨링·QA 실무 경험
  • 교육(수능·내신) 콘텐츠 관련 경험
이런 분이면 잘 맞아요
  • 작은 오류도 그냥 넘기지 않고 끝까지 확인하는 분
  • 반복 업무 안에서도 패턴을 찾아 프로세스를 개선하려는 분
