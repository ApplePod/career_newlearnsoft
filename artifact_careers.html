About Pass AI

"생성"이 아니라 채점입니다.
다섯 단계 모두 통과해야 문항이 됩니다.

일반 LLM은 정답이 여러 개로 갈리거나, 배우지 않은 범위의 풀이를 그대로 통과시킵니다. Pass AI는 각 단계에 hard gate를 두어, 통과 못한 문항은 그 자리에서 REJECT 처리하고 사유를 남깁니다.

SOLVE

04
VALIDATE
형식·정답·유형 검수, 교과과정 밖 풀이는 즉시 탈락
HARD GATE
05
REVIEW
ACCEPT / HOLD / REJECT 최종 분류, 사유 전량 추적
FINAL

Overview

풀잇은 학생이 매일 푸는 문제 데이터를 쌓아 약점 단원·유형을 진단하고 다음 문제를 추천하는 적응형 학습 서비스입니다. 문항 생성 파이프라인은 이미 구축돼 있고, 다음 과제는 이 데이터를 학생 개개인에게 연결하는 일입니다.

주요 업무

  • 지식그래프·난이도 데이터 활용 개인화 추천 모델 구축

자격 요건
  • Python 기반 데이터 분석·ML 실무 2년 이상
  • 추천 시스템·개인화·교육 데이터 분석 경험
