About Pass AI

"생성"이 아니라 평가 공정입니다

일반 LLM은 정답이 하나로 결정되지 않거나, 교과과정 밖 도구로 풀이하는 문제를 그대로 통과시킵니다. Pass AI는 각 단계가 hard gate를 가진 제약 생성 파이프라인입니다.

pass-ai · math-pipeline · run --watch
01INPUT 유형·난도·정답 슬롯 사전 제약 PASS
02GENERATE Kanana·Qwen 기반 지문·문항 생성 PASS
03SOLVE 독립 Solver가 재풀이, 정답 유일성 검산 HARD GATE
04VALIDATE 교과과정 그래프 매핑, 범위 밖 풀이 차단 HARD GATE
05REVIEW ACCEPT / HOLD / REJECT + 사유 기록 ACCEPT
Same Problem, Different Solve
f(x) = x² + 2x + 1, x ∈ ℝ 의 최솟값을 구하시오. 고1 수학 · 이차함수 단원 출제
✕ 교과과정 위반일반 LLM
f'(x) = 2x + 2 = 0
∴ x = -1, 최솟값 f(-1) = 0
사용 도구: 도함수·미적분 (고2~3 단원 · 출제범위 밖)
✓ 교과과정 내뉴런소프트 Pass AI
f(x) = (x + 1)²
∴ x = -1일 때 최솟값 0
사용 도구: 완전제곱식·꼭짓점 (중3~고1 단원 · 출제범위 안)

같은 정답이어도 교과과정 밖 도구로 풀면 무효입니다. Solver가 풀이 단계마다 사용된 개념을 교과과정 그래프에 매핑해 자동 검수합니다.
